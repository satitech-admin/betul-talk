# Betul Talks — News + Advertisement Platform

Production-style responsive PWA preview for Betul Talks Media Work Pvt. Ltd.

## Included
- Responsive news home, breaking ticker, categories
- Story detail reader
- Video/Reels experience
- Advertisement marketplace
- Business listings and CTA
- Explore/search/profile screens
- Web Admin preview for news, videos, ads and campaign management
- Browser-based preview CMS
- PWA manifest + service worker
- GitHub Pages deployment workflow

## Brand
- Primary: #D71920
- Accent: #F4B400
- White-first UI, dark Reels experience
- Inter + Noto Sans Devanagari

## Content sourcing
The preview only includes externally sourced Betul Talks items that can be publicly indexed/verified. A full automatic import of all Instagram posts, reels and advertisements requires official Instagram Graph API / Meta access. Production should not rely on scraping.

## Production next layer
Connect Supabase/PostgreSQL for persistence, Supabase Auth, storage/CDN, Firebase notifications, and Instagram Graph API for owned-account media sync.
